🎒 수업 · 준비

노트북이 매번 바뀌는데, 내 작업은 어디에 있나요?+

원본은 GitHub에 있어요. 노트북은 작업하는 자리일 뿐이에요. 수업을 시작할 때 GitHub에서 가져오고, 끝날 때 다시 올리면 어느 노트북에서든 이어서 할 수 있어요. 시작할 때 쓰는 프롬프트는 1부 시작 · 2부 시작 절차에 있어요.

🔗 이 질문 주소 복사

수업 끝나기 전에 꼭 해야 하는 게 있나요?+

두 가지예요. ① GitHub에 저장하기 — 저장하기 프롬프트를 보내요. ② 로그아웃하기 — 공용 노트북이라 GitHub · Supabase · Claude에서 꼭 나와요.

🔗 이 질문 주소 복사

GitHub 비밀번호가 기억나지 않아요.+

GitHub 로그인 화면의 Forgot password? 를 누르면 가입한 이메일로 다시 만드는 링크가 와요. 이메일에 로그인할 수 있어야 하니, 이메일 비밀번호도 함께 챙겨두세요. 수업 중이면 바로 손을 들어주세요.

🔗 이 질문 주소 복사

집에서도 이어서 할 수 있나요?+

네. 집 컴퓨터에 VS Code와 Claude Code를 설치하고 GitHub로 로그인하면, 수업 때처럼 가져와서 이어서 할 수 있어요. 2부(Next.js)라면 Node도 설치해야 해요.

🔗 이 질문 주소 복사

수업을 빠졌어요. 무엇부터 보면 되나요?+

수업 노트에서 그 회차를 열어 핵심을 먼저 읽고, 이 회차 프롬프트를 위에서부터 순서대로 따라 해보세요. 막히는 곳은 수업 시간에 함께 봐요.

🔗 이 질문 주소 복사

맥(Mac)을 써도 되나요?+

네. 같은 프로그램이 맥에도 있어요. 키보드 단축키만 조금 달라요. 예를 들어 Ctrl 대신 Cmd를 눌러요. 페이지 소스 보기는 맥 크롬에서 Cmd + Option + U 예요.

🔗 이 질문 주소 복사

🤖 Claude Code 쓰기

어떻게 부탁해야 잘 알아들어요?+

세 가지만 기억하세요. ① 무엇을 바꿀지 하나만 ② 어떻게 되면 좋을지 ③ 나머지는 그대로 두라는 한 줄. 예) "상품 이름을 더 크게 해주세요. 다른 기능은 건드리지 마세요."

🔗 이 질문 주소 복사

부탁했더니 다른 곳까지 바뀌었어요.+

바로 되돌리기를 보내요. 그다음 안전 프롬프트를 먼저 붙이고, 더 작게 나눠서 다시 부탁해요.

🔗 이 질문 주소 복사

Claude가 "진행할까요?" 하고 계속 물어봐요.+

정상이에요. 파일을 고치기 전에 허락을 받는 거예요. 무엇을 하려는지 읽어보고 괜찮으면 Yes를 눌러요. 모르겠으면 "무엇을 하려는지 쉽게 설명해줘"라고 물어봐도 돼요.

🔗 이 질문 주소 복사

영어로 대답해요.+

"한국어로 짧게 설명해줘"라고 한 줄 붙이면 돼요. 프롬프트 끝에 늘 붙여두셔도 좋아요.

🔗 이 질문 주소 복사

대답이 너무 길고 어려워요.+

"나는 초보자야. 세 줄로 쉽게 설명해줘"라고 다시 물어보세요. 모르는 말은 쉬운 말 사전에서도 찾아볼 수 있어요.

🔗 이 질문 주소 복사

"사용량 한도에 도달했다"고 나와요.+

Claude는 요금제마다 일정 시간 동안 쓸 수 있는 양이 정해져 있어요. 잠시 기다리면 다시 쓸 수 있어요. 수업 중이면 손을 들어주세요. 한 번에 아주 긴 부탁을 여러 번 하는 것보다, 짧게 나눠 부탁하는 게 양도 덜 들어요.

🔗 이 질문 주소 복사

Claude가 틀린 걸 맞다고 해요.+

AI도 틀려요. 그래서 수업에서 늘 직접 확인했어요. 금액은 계산기로, 저장은 Supabase 표로, 검색에 보이는지는 Ctrl + U로요. 틀린 걸 찾으면 "[무엇]이 [어떻게] 나와요. 원래는 [이렇게] 되어야 해요"라고 알려주세요.

🔗 이 질문 주소 복사

📦 GitHub · 저장

commit 과 push 가 뭐가 달라요?+

commit은 지금 상태를 사진 찍듯 기록해두는 것, push는 그 기록을 GitHub 창고로 올리는 것이에요. 둘 다 해야 GitHub에 올라가요. 저장 프롬프트가 둘 다 해줘요.

🔗 이 질문 주소 복사

push 가 실패했대요.+

먼저 빨간 메시지를 그대로 복사해서 GitHub 오류 프롬프트로 보내요. 다른 사람 계정으로 로그인돼 있거나, 다른 컴퓨터에서 먼저 올린 게 있으면 자주 생겨요.

🔗 이 질문 주소 복사

git 기록에 다른 사람 이름이 남아 있어요.+

공용 노트북이라 그래요. 9회차 '작성자 정보 확인' 프롬프트로 이 폴더에서만 내 이름으로 바꿔요. 컴퓨터 전체 설정은 건드리지 않아요.

🔗 이 질문 주소 복사

저장소를 공개(public)로 해도 괜찮아요?+

코드 자체는 괜찮아요. 다만 비밀 키 · 비밀번호 · 실제 개인정보는 절대 올리면 안 돼요. 그래서 키는 .env.local에 따로 두고, 그 파일은 GitHub에 올라가지 않게 했어요.

🔗 이 질문 주소 복사

실수로 비밀 키를 GitHub에 올렸어요.+

지우는 것만으로는 부족해요. 예전 기록에 남아 있어요. Supabase의 Settings → API Keys에서 그 키를 새로 만들고 예전 키는 지워요(쓰지 못하게 해요). 그다음 새 키로 바꿔 넣어요. 혼자 하기 어려우면 바로 알려주세요.

🔗 이 질문 주소 복사

저장소 이름을 바꾸고 싶어요.+

GitHub 저장소의 Settings에서 바꿀 수 있어요. 다만 1부 사이트 주소(github.io)가 함께 바뀌고, Vercel은 다시 연결해야 할 수 있어요. 이미 사람들에게 주소를 알려줬다면 바꾸지 않는 게 좋아요.

🔗 이 질문 주소 복사

🌐 인터넷에 올리기

고쳤는데 인터넷 사이트는 그대로예요.+

내 컴퓨터 → GitHub → 인터넷 사이트, 세 곳은 따로예요. GitHub에 다시 올렸는지 먼저 봐요. 1부(GitHub Pages)는 반영까지 몇 분 걸리고, 2부(Vercel)는 Deployments에서 Ready가 되면 반영돼요. 그래도 그대로면 새로고침하거나 시크릿 창으로 열어봐요.

🔗 이 질문 주소 복사

1부 사이트와 2부 사이트는 무슨 관계예요?+

1부(github.io)는 파일 하나로 만든 사이트, 2부(vercel.app)는 Next.js로 옮긴 사이트예요. Supabase는 둘이 같이 써요. 그래서 같은 계정으로 로그인되고, 상품도 같아요.

🔗 이 질문 주소 복사

내 사이트 주소를 짧게 바꿀 수 있나요? (도메인)+

네. 도메인(예: mystore.kr)을 사서 Vercel이나 GitHub Pages에 연결할 수 있어요. 도메인은 유료이고, 연결 방법은 각 서비스의 도메인 설정 화면에 안내돼 있어요.

🔗 이 질문 주소 복사

카톡으로 보냈더니 미리보기가 안 떠요.+

가게 이름 · 소개 · 대표 사진을 페이지에 적어줘야 떠요. 카톡 미리보기 프롬프트를 써보세요. 이미 한 번 보낸 링크는 예전 미리보기가 남아 있을 수 있어서, 새 대화방에서 확인해요.

🔗 이 질문 주소 복사

Vercel 배포가 실패했어요.+

Vercel의 빨간 메시지를 복사해서 "배포가 실패했습니다. 이 메시지를 보고 원인을 알려주세요."와 함께 보내요. 키를 안 넣었거나 이름 철자가 다른 경우가 많아요.

🔗 이 질문 주소 복사

휴대폰에서는 화면이 이상해요.+

17회차 휴대폰 화면 정리 프롬프트를 써요. 디자인을 크게 바꾸는 중이면, 모양이 다 정해진 맨 마지막에 하는 게 두 번 일하지 않아요.

🔗 이 질문 주소 복사

🗄️ Supabase · 데이터

상품이 하나도 안 나와요.+

순서대로 봐요. ① Supabase 프로젝트가 Paused(멈춤)인지 ② 상품 표의 읽기 문이 열렸는지(12회차 SQL) ③ 2부 인터넷 사이트라면 Vercel에 키를 넣고 다시 배포했는지(19회차).

🔗 이 질문 주소 복사

Supabase 화면에 "Paused"라고 나와요.+

무료 프로젝트는 일주일 동안 아무도 쓰지 않으면 잠시 멈춰요. 데이터는 그대로 있어요. Supabase에 들어가 그 프로젝트의 Restore를 누르면 몇 분 뒤 다시 켜져요. 오래 멈춰두면 복구가 어려워질 수 있으니 미루지 마세요.

🔗 이 질문 주소 복사

공개용 키와 비밀 키는 뭐가 달라요?+

Publishable(공개용) 키는 사이트에 넣어도 돼요. 손님 브라우저에서 쓰는 키라 '문(권한)'이 지켜줘요. Secret(비밀) 키는 모든 문을 열 수 있어서 사이트 · GitHub · 채팅 어디에도 넣지 않아요.

🔗 이 질문 주소 복사

상품 가격이나 이름은 어디서 고쳐요?+

Supabase의 Table Editor → products 표에서 칸을 눌러 고치고 저장해요. 사이트에서 새로고침하면 바로 바뀌어요. 가격은 쉼표나 '원' 없이 숫자만(18000) 넣어요.

🔗 이 질문 주소 복사

주문이 저장됐는지 어떻게 알아요?+

화면만으로는 알 수 없어요. Supabase Table Editor에서 orders(영수증)와 order_items(상품 줄)를 열어 새 줄이 생겼는지 봐요.

🔗 이 질문 주소 복사

다른 사람 장바구니가 보여요.+

'내 것만' 문이 안 열린 거예요. 13회차 SQL의 문 네 개(보기 · 담기 · 고치기 · 빼기)를 다시 붙여넣어 확인해요.

🔗 이 질문 주소 복사

시험으로 가입한 회원을 지우고 싶어요.+

Supabase Authentication → Users에서 그 사람을 골라 지울 수 있어요. 그 회원의 장바구니 · 주문도 함께 지워질 수 있으니, 실제 손님 정보가 아닌지 먼저 확인해요.

🔗 이 질문 주소 복사

가입했는데 로그인이 안 돼요.+

수업 때 끈 Confirm email 설정이 다시 켜져 있으면, 이메일 확인 전에는 로그인이 안 돼요. Supabase Authentication → Sign In / Providers → Email에서 확인해요. 비밀번호 오타도 한 번 더 봐요.

🔗 이 질문 주소 복사

실제 이름이나 전화번호로 시험해도 되나요?+

안 돼요. 연습할 때는 홍길동 · 010-0000-0000 · 서울시 테스트구 AI로 123 처럼 가짜 정보만 써요. 실제 개인정보는 한 번 저장되면 지우기도 신경 쓰이고, 지켜야 할 책임도 생겨요.

🔗 이 질문 주소 복사

🚗 2부 · Next.js · Vercel

localhost:3000 이 안 열려요.+

켜둔 창(터미널)을 닫으면 사이트가 꺼져요. "사이트가 안 열립니다. 다시 켜주세요."라고 부탁해요. 이 주소는 내 컴퓨터에서만 열려서 다른 사람에게 보낼 수 없어요.

🔗 이 질문 주소 복사

다른 컴퓨터에서 가져왔더니 실행이 안 돼요.+

부품(node_modules)과 키 쪽지(.env.local)는 GitHub에 없어서 새로 만들어야 해요. 2부 시작 절차가 둘 다 해줘요. 키는 다음 메시지로 따로 보내요.

🔗 이 질문 주소 복사

.env.local 은 왜 GitHub에 안 올라가요?+

키가 들어 있는 쪽지라서 일부러 빼둬요. 그래서 인터넷 사이트(Vercel)에는 Settings → Environment Variables에 같은 이름과 값을 따로 넣어요.

🔗 이 질문 주소 복사

Ctrl + U 를 눌렀는데 장바구니가 비어 있어요.+

정상이에요. 장바구니 · 주문내역은 나한테만 보이는 화면이라 미리 만들지 않아요. 상품 목록 · 상세처럼 모두에게 같은 화면만 소스에 내용이 있어야 해요.

🔗 이 질문 주소 복사

폴더가 갑자기 엄청 커졌어요.+

node_modules(부품 창고) 때문이에요. 정상이고, GitHub에는 올리지 않아요.

🔗 이 질문 주소 복사

1부 사이트는 이제 지워도 되나요?+

지우지 않는 걸 권해요. 1부 사이트는 그대로 잘 돌아가고, 무엇이 달라졌는지 비교할 수 있는 좋은 기록이에요. Supabase도 함께 쓰고 있어요.

🔗 이 질문 주소 복사

🎨 디자인 · 사진

인터넷에서 찾은 사진을 써도 되나요?+

함부로 쓰면 안 돼요. 다른 쇼핑몰 사진은 대부분 그 가게 것이에요. 직접 찍은 사진, 또는 무료로 쓰라고 공개한 사이트(예: Unsplash)의 사진을 쓰고, 출처를 적어두면 좋아요.

🔗 이 질문 주소 복사

사진 때문에 사이트가 느려요.+

큰 사진을 그대로 쓰면 휴대폰에서 늦게 떠요. 사진 가볍게 프롬프트를 써보세요.

🔗 이 질문 주소 복사

색이나 글꼴을 다시 바꾸고 싶어요.+

STYLE.md를 먼저 고친 다음 "STYLE.md 대로 사이트 전체를 바꿔주세요. 동작은 그대로 두고 모양만 바꿔주세요."라고 부탁해요. 기준을 먼저 바꾸는 게 핵심이에요.

💼 운영 · 비용 · 진짜 장사

이 사이트를 계속 무료로 쓸 수 있나요?+

GitHub Pages · Vercel · Supabase 모두 무료 요금제로 시작할 수 있어요. 다만 무료에는 사용량 한도와 조건이 있어요. 예를 들어 Supabase는 오래 안 쓰면 멈추고, Vercel 무료 요금제는 개인 · 비상업용이 기준이에요. 정확한 조건은 각 서비스의 요금 안내에서 확인해요.

🔗 이 질문 주소 복사

이걸로 실제 장사를 해도 되나요?+

지금 사이트는 상품 보여주기 · 회원 · 주문 받기까지 돼요. 실제로 팔려면 결제 연동, 사업자등록, 통신판매업 신고, 판매자 정보와 개인정보 처리 안내가 더 필요해요. 그리고 상업용으로 쓸 수 있는 요금제인지도 확인해야 해요. 23회차 '진짜 장사에 필요한 것들'을 참고하세요.

카드 결제를 붙일 수 있나요?+

가능해요. 카드 정보는 직접 받지 않고 결제 대행사를 통해요. 대행사 계약에는 보통 사업자등록이 필요하고 수수료가 있어요. 작은 가게는 주문만 받고 계좌로 입금받는 방식으로 먼저 시작하기도 해요.

수업이 끝나면 사이트는 어떻게 돼요?+

그대로 남아 있어요. 내 GitHub · Vercel · Supabase 계정에 있으니까요. 다만 Supabase가 멈추지 않도록 가끔 사이트에 들어가 보거나, 멈췄으면 Restore를 눌러요.

회사 업무에도 써먹을 수 있나요?+

네. 수업에서 쓴 방법은 그대로 통해요. 기준을 먼저 정하고 그대로 시키기, 나눠서 부탁하기, 결과를 직접 확인하기. 보고서 · 표 · 간단한 사내 페이지를 만들 때도 같아요. 회사 자료를 AI에 넣을 때는 회사 보안 규칙을 먼저 확인해요.

📘 이 사이트 쓰는 법

프롬프트는 어떻게 써요?+

수업 노트에서 어두운 프롬프트 카드의 복사를 누르고, Claude Code에 붙여넣어요. 노란색 [ ] 부분만 내 것으로 바꿔요.

'내 정보로 채우기'에 넣은 이름이 사라졌어요.+

일부러 저장하지 않아요. 공용 노트북이라 다음 사람이 보지 않도록, 그 화면을 떠나면 지워지게 했어요.

프롬프트를 한 번에 받아둘 수 있나요?+

수업 노트 '매번 쓰는 프롬프트'의 내려받기 버튼을 누르면 모든 프롬프트가 글 파일 하나로 받아져요.
